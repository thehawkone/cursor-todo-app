# Планировщик задач (Todo App)

Простое одностраничное приложение для управления списком дел. Работает в браузере, данные сохраняются локально и не пропадают после перезагрузки страницы.

## Как запустить

1. Склонируйте или скачайте проект.
2. Откройте файл `index.html` в браузере (двойной клик или через расширение **Live Server** в VS Code / Cursor).
3. Приложение готово к работе — установка зависимостей не требуется.

> **SCSS:** стили уже скомпилированы в `styles/main.css`. Если вы меняете `styles/main.scss`, пересоберите CSS:
>
> ```bash
> npx sass styles/main.scss styles/main.css
> ```

## Как пользоваться

### Добавить задачу

1. Введите текст в поле **«Введите новую задачу…»**.
2. Нажмите **«Добавить»** или клавишу **Enter**.
3. Задача появится в списке ниже.

Пустой текст добавить нельзя — появится предупреждение.

### Отметить задачу выполненной

- Установите **галочку** слева от текста задачи.
- Текст задачи будет зачёркнут.
- Снимите галочку, чтобы вернуть задачу в активные.

### Удалить одну задачу

1. Нажмите кнопку **«Удалить»** справа от нужной задачи.
2. Подтвердите удаление в диалоговом окне.

### Редактировать задачу

- **Кликните по тексту** задачи.
- В появившемся окне введите новый текст и нажмите **OK**.
- Нажмите **Отмена**, если менять текст не нужно.

### Очистить все выполненные задачи

Кнопка **«Очистить выполненные»** появляется только когда есть хотя бы одна задача с галочкой.

1. Нажмите **«Очистить выполненные»**.
2. Подтвердите действие.
3. Все выполненные задачи будут удалены; активные останутся.

### Счётчик задач

Когда в списке есть задачи, отображается:

- **Текущие задачи** — общее количество задач.
- **Осталось задач** — количество невыполненных задач.

Если задач нет, вместо счётчика показывается сообщение: **«Пока задач нет. Добавьте первую!»**

## Сохранение данных

Все задачи хранятся в **localStorage** браузера под ключом `todo-tasks`.

- Данные сохраняются автоматически после каждого изменения.
- После обновления страницы (**F5**) список и статус задач (активная / выполненная) сохраняются.
- Если очистить данные сайта в браузере, список задач будет удалён.

## Структура проекта

```
cursor-todo-app/
├── index.html       # разметка страницы
├── styles/
│   ├── main.scss    # исходные стили
│   └── main.css     # скомпилированные стили
└── js/
    ├── app.js       # точка входа, запуск приложения
    ├── ui.js        # интерфейс: форма, список, события
    ├── store.js     # логика: добавление, удаление, редактирование
    └── model.js     # сохранение и загрузка из localStorage
```
